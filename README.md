# Controle no Celular

Página para lançar compras, pagamentos e viagens no celular e gerar o arquivo que a planilha "Controle Financeiro Pessoal" lê.

- Não há nenhum dado pessoal neste repositório. Pessoas, cartões, lojas e saldos entram pelo arquivo `resumo-celular.json` exportado pela planilha e ficam guardados só no navegador do celular.
- Funciona sem internet depois do primeiro acesso (instale pela opção "Adicionar à tela inicial").
- O botão "Salvar arquivo para a planilha" gera `controle-celular-<pessoa>-<aparelho>.csv`; a planilha junta os arquivos de todos os celulares.
